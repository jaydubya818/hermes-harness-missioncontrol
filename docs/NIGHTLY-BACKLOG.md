- [ ] 2026-08-27 — **Stop the console hand-mirroring the orchestrator's step-action guards — the read model should say which actions are available.** This is a *design proposal raised in place of a third patch*, under the nightly whack-a-mole rule: two prior nightly commits have now fixed `apps/harness-console/src/App.tsx` for the same class of bug — `d6e8f7a` (Retry offered on a cancelled step, which the route had 409'd since 2026-08-22) and `aa9875d` (Execute/Mark-complete offered on non-current steps). Both were the same failure: a route guard was tightened server-side and the JSX condition that mirrors it was not. The cause is structural. `buildMissionsReadModel()`'s `run_cards` returns raw state — `status`, `current_step_id`, and per step `state`, `risk`, `blocked_reason`, `artifacts_count` — and the console re-derives every operator control from it by hand, so each of the six step/run actions carries a private copy of its route's precondition. Two of the six have already drifted. The remaining four have not drifted but are held correct only by an unpinned engine invariant, which is the same setup that produced the first two: `POST /api/runs/:id/resume-step` requires `current.state === "paused" && run.status === "paused"` while the console checks only `step.state === "paused"`, and `POST /api/runs/:id/cancel` returns `400 "no current step"` for a condition the console never tests. Both are unreachable today only because `transitionCurrentStep` is the sole writer of `run.status` and always sets `"paused"` alongside a paused step, and because `current_step_index` never advances past the last step — neither fact is asserted anywhere, and hydration accepts a persisted run that violates both. The durable fix is to compute the guard once, on the server, next to the route it governs: emit a per-step `available_actions` (and a per-run equivalent) in the run-card read model and have the console render exactly what it is handed. That deletes six mirrored predicates and makes the next route tightening impossible to forget.
